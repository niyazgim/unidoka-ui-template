# Unidoka UI template

## How to start

### 1. (optional) Add subdomains to your hosts file

```
127.0.0.1  subdomain-name.localhost
```

### 2. Install deps

```bash
npm i
```

### 3. Run

```bash
npm run dev
```

### 4. (optional) run repomix to get all files context (for chat AIs)

```bash
repomix .
```
